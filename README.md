# AI Agent Systems Portfolio

Портфолио архитектурных кейсов по ИИ-агентам, мультиагентным системам и AI PDLC. Здесь собраны решения, в которых можно посмотреть логику работы, продуктовый контекст, ключевые архитектурные решения и результаты — без публикации исходного кода.

> [!IMPORTANT]
> Этот репозиторий не является open-source-версией рабочих систем. Исходный код, клиентские данные, конфигурации, промпты, ключи доступа, внутренние URL, журналы и материалы разработки не публикуются из-за договорных обязательств и требований конфиденциальности.

## Принцип публикации

Каждый кейс отвечает на четыре вопроса:

1. Какую задачу решает система.
2. Как устроены основные компоненты и их взаимодействие.
3. Какие инженерные решения были приняты и почему.
4. Каким результатом или продуктовой метрикой подтверждается полезность решения.

Описание построено на обобщённых схемах. Названия клиентов, коммерческие условия, внутренние роли, точные данные и реализация опущены либо заменены нейтральными формулировками.

## Хронология

Этот репозиторий фиксирует дату публикации портфолио-кейса, а не дату исходной разработки. Реальные периоды работы указываются в каждом кейсе явно, например: `Исходное решение разработано: июнь 2024 — май 2026`.
